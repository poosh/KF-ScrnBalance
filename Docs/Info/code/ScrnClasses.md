# ScrnBalanceSrv class taxonomy

**Generated version: v9.74.35**

Every class in `ScrnBalanceSrv/Classes/` (638 classes; `ScrnUnicode.uc` is a UTF-16 string table and is skipped), split by whether it is an **Actor**
or a non-Actor **Object**. Generated by resolving each `extends` chain through the other
`Scrn*` packages and `kfsrc/` down to `Actor` / `Object`.

Regenerate with the `scrn-gen-classes` skill. Do not hand-edit — changes are overwritten.

**Why this split matters:** when an actor is destroyed, the engine clears references to it
only inside other actors. A non-Actor `Object` is never visited, so an actor reference stored
in one dangles after the actor is freed and crashes during garbage collection. Classes under
**Objects** below must therefore never hold an actor reference across a frame boundary —
see the *Actor references held by non-Actor `Object`s* section of `CLAUDE.md`.

Two KF specifics worth knowing, both verified against `kfsrc/` rather than assumed from stock
UE2.5: **`DamageType extends Actor`** in KF (it is an `Object` in stock UT2004), and
**`WeaponFire extends Object`** — the one non-Actor family the engine cleans up anyway,
through the weapon that owns it.

Abstract classes are listed separately at the end. Counts: **520** concrete, **118** abstract.
